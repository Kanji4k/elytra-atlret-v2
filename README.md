# Elytra Alert 2.1.0 (rebuilt, adds Alert volume 0-1000%)
Source reconstructed from elytra-alert-2_0_0.jar. Build with GitHub Actions (Actions > run > Artifacts > elytra-alert-jar).
New: Mod Menu > Elytra Alert > "Alert volume" slider (0-1000%, 10% steps, default 100%). Click the sound button to test.
Minecraft limits one sound instance to 100%, so above 100% the mod plays several copies at once (1000% = 10 copies).
Keep Minecraft's Master volume up, and lower the slider if your speakers/headphones distort.
